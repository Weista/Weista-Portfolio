02 · System Architecture

A design system built like code

系统架构 · 像代码一样被管理的设计系统

Three layers — Global Styles (tokens), Components, and Materials — are versioned, documented, and consumed as primitives so design and engineering stay in lockstep.

【 分层治理 】Layered

Global Styles define the raw tokens — color, typography, effects, values. Components compose those tokens into reusable primitives. Materials package real product screens, brand resources, email and upsell templates.

4Token families 26+Component groups 5Material packs
【 规模化 】Scalable

Because every visual decision flows from tokens, a change can be pushed once and propagated across every product surface and screen state — no drift, no inconsistency.

100%Consistency 80%Faster design-to-dev

06 · Design Principles

What the system stands for

设计原则 · 为 B2B 与 AI 而生
A

Accessible by default

Tokenized color pairs are chosen for WCAG AA contrast on every surface, with focus, keyboard, and screen-reader states built into every component.

D

Data-dense, not messy

B2B compensation data needs density without chaos — tables, filters, badges and status color are engineered so thousands of rows stay readable.

AI

AI-first, human-checked

Dedicated AI kits (assistant, prompt input, conversations, generated-content tags) make AI output trustworthy and visibly attributed.

T

Token-driven scale

Every color, type, radius and shadow flows from 138 tokens, so a single source of truth keeps six products visually identical.

P

Privacy-aware deployment

Sensitive compensation data supports on-prem / local deployment for latency and compliance, and the UI is designed to adapt gracefully.

F

Fast design → dev

Components are paired with exact tokens and state matrices, bridging design and engineering and cutting handoff rework dramatically.
